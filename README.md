# GastricUltrasoundPrivacy Policy
This Privacy Policy describes how the Gastric Ultrasound Calculator App ("the App") handles information.

1. Data Collection and Storage
The App is designed solely as a medical decision-support tool for healthcare professionals.

No Personal Data Collection: The App does not require, collect, store, or transmit any personally identifiable information (PII) about the patient, the user, or the user's device.

No Data Storage: The App does not store any calculation results or inputs (such as antral area, patient height, or weight) after the user closes the calculation screen or exits the App. All data is processed in temporary, volatile memory and is immediately discarded.

No Internet Connectivity: The App does not connect to the internet, and therefore, it cannot transmit any data to any external server or third party.

2. Use of Collected Data
Since the App does not collect any data, there is no data to use or share. The sole function of the inputs provided by the user (antral area, height, weight) is to perform the required mathematical calculation to assist the user in determining gastric risk.

3. Third-Party Services
The App does not integrate or use any third-party analytics, advertising, or monitoring services.

4. Security
Given that no data is collected, stored, or transmitted, there is no risk of data breach or unauthorized access to user or patient information through this App.

5. Compliance with Laws
This App is not intended to be a substitute for professional medical judgment. It is the responsibility of the medical professional using this tool to ensure compliance with all applicable laws and regulations, including HIPAA or other patient privacy standards.

6. Changes to This Privacy Policy
We may update our Privacy Policy from time to time. We will notify you of any changes by posting the new Privacy Policy here.
